TECHTRACK PH - GITHUB PAGES DEPLOYMENT

This folder contains the six Stitch screens arranged as a static website.

Files:
- index.html (Overview / homepage)
- introduction.html
- discussion.html
- significance.html
- research-team.html
- references.html

Navigation links have been updated to point to the corresponding HTML files.

PUBLISHING:
1. Open your GitHub repository.
2. Upload the CONTENTS of this folder to the repository root (not the ZIP file itself, and not the enclosing folder).
3. Commit the files to the main branch.
4. Open Settings > Pages.
5. Set Source to Deploy from a branch.
6. Select branch main and folder /(root), then Save.
7. Wait for GitHub Pages to finish deploying.

The homepage must be named index.html and must be in the publishing root.

Note: The Stitch HTML uses Tailwind CDN, Google Fonts, Material Symbols, and some externally hosted Google image URLs. Those resources require an internet connection and availability from their original hosts.
